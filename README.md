# AMasoldt Portfolio

Mein persönliches Portfolio und Lernprojekt auf meinem Weg
in die Webentwicklung.

## Technologien

- HTML
- CSS
- JavaScript

## Funktionen

- Responsives Layout
- Dunkles Design mit blauen Akzenten
- Projektübersicht und Kontakt per E-Mail
- Tastaturbedienung mit sichtbarem Fokus und Skip-Link
- Berücksichtigung von prefers-reduced-motion
- Automatische Jahresanzeige

## Lokal starten

Die Datei index.html in VS Code mit Live Server öffnen.
